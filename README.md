# project1
A beautifully designed real-time weather app built with HTML,CSS, and JavaScript featuring live API data, smooth animations, and an elegant modern interface

# Technologies Used

HTML

CSS

JavaScript

OpenWeatherMap API

Font Awesome

Google Fonts

# Features

Search weather by city

Shows temperature and weather condition

Displays wind, humidity, visibility, pressure

Quick search buttons for cities

Loading indicator while fetching data

Error message for wrong city

Responsive and clean UI

Works with Enter key or Search button
